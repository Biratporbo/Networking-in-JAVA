# 18. SSH FUNDAMENTALS

## 🔴 VERY IMPORTANT

### 1. What is SSH?
Answer: SSH stands for Secure Shell. It is a protocol used for secure remote access and administration of systems over a network.  

🧠 Memorize:  
SSH = Secure remote access

### 2. Why is SSH used?
Answer: SSH is used for securely accessing and administering remote systems, executing commands, and securely transferring data.  

🧠 Memorize:  
SSH = Remote administration securely

### 3. What port does SSH normally use?
Answer: SSH normally uses TCP port 22.  

🧠 Memorize:  
SSH = 22

### 4. SSH vs Telnet
Answer: SSH provides encrypted and secure communication, while traditional Telnet sends communication without encryption.  

🧠 Memorize:  
SSH = Secure  
Telnet = Insecure/plaintext

### 5. How does SSH provide security?
Answer: SSH provides security through encryption, authentication, and integrity protection.  

🧠 Memorize:  
SSH = Encryption + Authentication + Integrity

### 6. What is SSH key-based authentication?
Answer: SSH key-based authentication uses a pair of cryptographic keys: a public key and a private key. The public key is placed on the server, while the private key remains with the user.  

🧠 Memorize:  
Public → Server  
Private → User

### 7. Password vs public-key authentication
Answer: Password authentication uses a password, while public-key authentication uses cryptographic keys and is generally preferred for secure automated access.  

🧠 Memorize:  
Password = password  
Public key = key pair

---

## 🟠 IMPORTANT

### 8. What is an SSH public key?
Answer: The public key is the key that can be shared and is typically stored on the remote server for key-based authentication.  

🧠 Memorize:  
Public = share/store on server

### 9. What is an SSH private key?
Answer: The private key is the secret part of the key pair and must be protected from unauthorized access.  

🧠 Memorize:  
Private = Secret

### 10. Why should a private key be protected?
Answer: Anyone who obtains an improperly protected private key may potentially use it to authenticate as the key owner, depending on the configuration.  

🧠 Memorize:  
Private key leaked = Security risk

### 11. What is remote administration?
Answer: Remote administration means managing a computer or network device from another location through a network.  

🧠 Memorize:  
Remote administration = Manage system from somewhere else

### 12. What is SSH tunneling?
Answer: SSH tunneling uses an SSH connection to securely transport other network traffic between endpoints.  

🧠 Memorize:  
SSH tunnel = Other traffic through secure SSH connection

---

## 🟡 LOWER PRIORITY

### 13. Port forwarding
Answer: Port forwarding redirects traffic from one network endpoint/port to another endpoint/port.  

🧠 Memorize:  
Port forwarding = Redirect traffic

### 14. SSH agent
Answer: An SSH agent is a program that can securely manage private keys and perform authentication on behalf of SSH clients.  

🧠 Memorize:  
SSH agent = Manages keys

### 15. SSH configuration files
Answer: SSH configuration files contain settings controlling SSH client or server behavior.  

🧠 Memorize:  
SSH config = SSH settings
