# 17. VPN FUNDAMENTALS

## 🔴 VERY IMPORTANT

### 1. What is a VPN?
Answer: VPN stands for Virtual Private Network. It creates a secure logical connection over an untrusted network such as the Internet.  

🧠 Memorize:  
VPN = Secure private connection over public network

### 2. Why is VPN used?
Answer: VPN is used to provide secure remote access, protect communication over untrusted networks, and connect private networks securely.  

🧠 Memorize:  
VPN = Secure remote/network communication

### 3. What is tunneling?
Answer: Tunneling is the process of encapsulating network traffic inside another protocol to transport it across a network.  

🧠 Memorize:  
Tunneling = Traffic inside another connection

### 4. How does VPN provide secure communication?
Answer: A VPN can use tunneling, encryption, and authentication to protect data while it travels across an untrusted network.  

🧠 Memorize:  
VPN security = Tunnel + Encryption + Authentication

### 5. What is encryption?
Answer: Encryption converts readable data into an unreadable form so that unauthorized people cannot easily understand it.  

🧠 Memorize:  
Readable → encrypted/unreadable → authorized party decrypts

### 6. What is remote-access VPN?
Answer: A remote-access VPN allows an individual user or device to securely connect to a private organizational network from a remote location.  

🧠 Memorize:  
User → VPN → Company network

### 7. What is site-to-site VPN?
Answer: A site-to-site VPN securely connects two or more entire networks over a public network.  

🧠 Memorize:  
Network → VPN → Network

### 8. Remote-access vs site-to-site VPN
| Remote-access VPN | Site-to-site VPN |
|-------------------|------------------|
| Connects individual users/devices | Connects networks |
| Used by remote employees | Used between offices/sites |
| User-oriented | Network-oriented |

🧠 Memorize:  
Remote = User  
Site-to-site = Network

## 🟠 IMPORTANT

### 9. VPN vs proxy
Answer: A proxy generally acts as an intermediary for particular application traffic, while a VPN typically creates a protected network connection for traffic between the device and VPN endpoint.  

🧠 Memorize:  
Proxy = intermediary  
VPN = protected network connection

### 10. VPN vs firewall
Answer: A VPN primarily provides secure connectivity, while a firewall controls and filters network traffic based on security rules.  

🧠 Memorize:  
VPN = Secure connection  
Firewall = Traffic control

### 11. What is IPsec?
Answer: IPsec is a set of protocols used to secure IP communications through mechanisms such as authentication and encryption.  

🧠 Memorize:  
IPsec = Security for IP communication

### 12. What is SSL/TLS VPN?
Answer: An SSL/TLS VPN uses SSL/TLS-based security to provide protected remote access, commonly through web-based or client-based access.  

🧠 Memorize:  
SSL/TLS VPN = Secure remote access using TLS

### 13. What is a VPN tunnel?
Answer: A VPN tunnel is a logical protected path through which VPN traffic is encapsulated and transported between endpoints.  

🧠 Memorize:  
VPN tunnel = Protected logical path

---

## 🟡 LOWER PRIORITY

### 14. IKE
Answer: IKE stands for Internet Key Exchange. It is used with IPsec to negotiate security parameters and establish keys for secure communication.  

🧠 Memorize:  
IKE = Negotiates IPsec security

### 15. IPsec modes
Answer: IPsec has two main modes:  
- Transport mode – protects the IP payload.  
- Tunnel mode – encapsulates and protects the entire original IP packet.  

🧠 Memorize:  
Transport = Payload  
Tunnel = Entire IP packet

### 16. VPN authentication mechanisms
Answer: VPN authentication verifies the identity of users or devices. Common mechanisms include passwords, certificates, pre-shared keys, and multi-factor authentication depending on the VPN system.  

🧠 Memorize:  
Authentication = Prove who you are
