# 7. SUBNETTING FUNDAMENTALS

## 🔴 VERY IMPORTANT

### 1. What is subnetting?
Answer: Subnetting is the process of dividing one large IP network into smaller logical networks called subnets.  

🧠 Memorize:  
One big network → smaller networks = Subnetting

### 2. Why do we use subnetting?
Answer: Subnetting is used to efficiently use IP addresses, reduce broadcast traffic, improve network organization, and improve security.  

🧠 Memorize:  
Subnetting = IP efficiency + less broadcast + organization + security

### 3. What is a subnet mask?
Answer: A subnet mask identifies which portion of an IPv4 address represents the network and which portion represents the host.  

Example:  
255.255.255.0 = /24  

🧠 Memorize:  
Subnet mask = Network part + Host part

### 4. What is CIDR?
Answer: CIDR stands for Classless Inter-Domain Routing. It represents an IP network using a prefix length such as /24, /16, or /27.  

🧠 Memorize:  
CIDR = IP + slash notation

### 5. What does /24 mean?
Answer: /24 means that the first 24 bits are network bits and the remaining 8 bits are host bits.  

Subnet mask:  
255.255.255.0  

🧠 Memorize:  
/24 → 24 network bits + 8 host bits

### 6. What is a network address?
Answer: A network address identifies the network itself. It is the first address in a subnet and cannot normally be assigned to a host.  

Example:  
192.168.1.0/24  
Network address = 192.168.1.0  

🧠 Memorize:  
First address = Network address

### 7. What is a broadcast address?
Answer: A broadcast address is used to send traffic to all hosts within an IPv4 subnet. It is normally the last address in the subnet.  

Example:  
192.168.1.255  

🧠 Memorize:  
Last address = Broadcast

### 8. What is a host address?
Answer: A host address is an IP address assigned to an individual device within a subnet.  

Example:  
192.168.1.50  

🧠 Memorize:  
Device's usable IP = Host address

### 9. What is a default gateway?
Answer: A default gateway is the device, usually a router, that a host uses to communicate with destinations outside its local network.  

🧠 Memorize:  
Outside my network → Default Gateway

### 10. What is the difference between network bits and host bits?
Answer: Network bits identify the network, while host bits identify individual devices within that network.  

🧠 Memorize:  
Network bits → Network  
Host bits → Devices

### 11. How does subnetting reduce broadcast traffic?
Answer: Subnetting divides a large broadcast domain into smaller subnets. Broadcast traffic is therefore limited to the local subnet instead of reaching the entire network.  

🧠 Memorize:  
Smaller subnet → Smaller broadcast domain

## 🔴 Calculation Questions

### 12. How many hosts can a /24 network support?
Answer:  
Host bits: 32 - 24 = 8  
Total addresses: 2⁸ = 256  
Usable hosts: 256 - 2 = 254  

✅ Answer: 254 usable hosts  

🧠 Memorize:  
Hosts = 2^(host bits) - 2

### 13. How many hosts can a /25 network support?

2⁷ = 128  
Usable: 128 - 2 = 126  

✅ Answer: 126 usable hosts  

🧠 Memorize:  
/25 → 126 hosts

### 19. Given 192.168.1.50/24, find the network address
Network address = 192.168.1.0  

🧠 Memorize:  
/24 → last octet becomes 0 for network address

### 20. Given 192.168.1.50/24, find the broadcast address
Broadcast address = 192.168.1.255  

🧠 Memorize:  
/24 → .0 network, .255 broadcast

### 21. Given an IP and subnet mask, find the usable host range
Example: 192.168.1.50/24  
Network: 192.168.1.0  
Broadcast: 192.168.1.255  
Usable host range: 192.168.1.1 – 192.168.1.254  

🧠 Memorize:  
Network + 1 → First host  
Broadcast - 1 → Last host

### 22. Divide 192.168.1.0/24 into 4 subnets
Borrow 2 bits → /26  
Each /26 = 64 addresses  

Subnets:  
- 192.168.1.0/26 → Hosts .1–.62, Broadcast .63  
- 192.168.1.64/26 → Hosts .65–.126, Broadcast .127  
- 192.168.1.128/26 → Hosts .129–.190, Broadcast .191  
- 192.168.1.192/26 → Hosts .193–.254, Broadcast .255  

🧠 Memorize:  
4 subnets → borrow 2 bits → /24 → /26

### 23. Divide a network into a specified number of subnets
Answer: To divide a network into a required number of subnets:  
- Determine how many subnet bits are needed.  
- Use 2ⁿ ≥ required subnets.  
- Borrow those bits from the host portion.  
- Calculate the new prefix length.  
- Determine network, host range, and broadcast addresses.  

Example: Need 8 subnets → 2³ = 8 → borrow 3 bits → /24 → /27  

🧠 Memorize:  
Required subnets → 2ⁿ → borrow n bits

### 24. Find the appropriate subnet for a given number of hosts
Answer: First determine the required number of host bits using:  
2ⁿ - 2 ≥ required hosts  

Example: Need 50 hosts → 2⁶ - 2 = 62 → /26  

✅ Answer: /26  

🧠 Memorize:  
Required hosts → 2ⁿ - 2 → find n → 32-n

## 🟠 Important

### 25. What is VLSM?
Answer: VLSM stands for Variable Length Subnet Mask. It allows different subnets to use different subnet masks according to their host requirements.  

🧠 Memorize:  
VLSM = Different subnet sizes

### 26. What is FLSM?
Answer: FLSM stands for Fixed Length Subnet Mask. It uses the same subnet mask for all subnets.  

🧠 Memorize:  
FLSM = Same subnet size

### 27. VLSM vs FLSM?
Answer:  

| VLSM | FLSM |
|------|------|
| Different subnet sizes | Same subnet sizes |
| More efficient IP usage | Can waste IP addresses |
| Flexible | Less flexible |

🧠 Memorize:  
VLSM = Variable  
FLSM = Fixed

### 28. What is supernetting?
Answer: Supernetting is the process of combining multiple smaller networks into a larger network block.  

🧠 Memorize:  
Subnetting = one → many  
Supernetting = many → one

### 29. What is route aggregation?
Answer: Route aggregation combines multiple network routes into a single summarized route. It reduces the size of routing tables.  

🧠 Memorize:  
Many routes → one summary route
