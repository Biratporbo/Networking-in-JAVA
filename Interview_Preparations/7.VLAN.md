# 7. VLAN

## 🔴 Very Important

### 1. What is VLAN?

**VLAN** stands for **Virtual Local Area Network**. It logically divides a physical switched network into separate **Layer 2 broadcast domains**.

### 2. Why use VLAN?

VLANs improve **network organization**, reduce **broadcast traffic**, and provide **logical separation** between groups of devices.

### 3. What is a broadcast domain?

A **broadcast domain** is a group of devices that receive **Layer 2 broadcast traffic** from one another.

### 4. How does VLAN reduce broadcast traffic?

Each VLAN forms a separate **broadcast domain**, so a broadcast sent within one VLAN normally does not propagate into other VLANs.

### 5. Can different VLANs communicate?

Not directly at **Layer 2**. They require **Layer 3 routing**.

### 6. What is inter-VLAN routing?

**Inter-VLAN routing** allows devices in different VLANs to communicate using a **router** or **Layer 3 switch**.

### 7. What is an access port?

An **access port** normally carries traffic for a **single VLAN** and is typically connected to an end device.

### 8. What is a trunk port?

A **trunk port** carries traffic for **multiple VLANs**, commonly between switches or between a switch and a router/Layer 3 device.

### 9. Access vs Trunk?

> **Access → one VLAN**

> **Trunk → multiple VLANs**

### 10. What is VLAN tagging?

**VLAN tagging** adds information to an Ethernet frame to identify which VLAN the frame belongs to, particularly when traffic travels across a trunk.

### 11. What is IEEE 802.1Q?

**IEEE 802.1Q** is the standard commonly used for **VLAN tagging** on Ethernet trunk links.

### 12. What is a VLAN ID?

A **VLAN ID** is a numerical identifier used to identify a VLAN.

---

## 🟠 Important

### 13. What happens when a broadcast is sent inside a VLAN?

The broadcast is forwarded to other ports belonging to the same VLAN, subject to the switch's behavior and configuration, but it is not normally forwarded into other VLANs.

### 14. Why are VLANs useful for security?

VLANs provide **logical separation** between groups of devices, which can help limit unnecessary communication. Additional controls such as **ACLs and firewalls** are still needed for security.

### 15. What is a native VLAN?

On an **802.1Q trunk**, the native VLAN is the VLAN whose traffic is sent **untagged by default**.

### 16. What is router-on-a-stick?

**Router-on-a-stick** is a configuration where one physical router interface uses multiple logical **subinterfaces** to perform routing between VLANs over a trunk connection.

### 17. What is a Layer 3 switch?

A **Layer 3 switch** is a switch that can perform both **Layer 2 switching** and **Layer 3 routing**.

### 18. VLAN vs subnet?

A **VLAN** is a **Layer 2 logical network/broadcast domain**, while a **subnet** is a **Layer 3 IP network**.

Often:

> **One VLAN ↔ one IP subnet**

But that is a common design practice, not a fundamental requirement.

### 19. Can multiple VLANs use the same subnet?

For an interview:

> Normally, each VLAN is assigned its own IP subnet because VLANs are separate Layer 2 broadcast domains. Using the same subnet across multiple VLANs creates design and routing problems and is generally not recommended.

## 🟡 Lower Priority

### 20. What is VLAN hopping?

**VLAN hopping** is an attack where an unauthorized device attempts to gain access to traffic belonging to another VLAN.

### 21. What is double-tagging?

**Double-tagging** is a VLAN-hopping technique where an attacker adds two VLAN tags to a frame to try to bypass VLAN segmentation.

### 22. What is dynamic VLAN assignment?

**Dynamic VLAN assignment** automatically places devices into VLANs based on criteria such as **user identity, device information, or authentication**.
