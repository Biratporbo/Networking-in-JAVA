# 3. DNS

You already know the basic DNS definition, so concentrate on these.

## 🔴 Very Important

### 1. What is DNS?

DNS, or Domain Name System, translates human-readable domain names into IP addresses and provides other naming information.

### 2. How does DNS resolution work?

A client first checks local information such as its DNS cache. If the answer isn't available, the DNS resolver queries the DNS hierarchy or its upstream servers to find the required record and returns the result to the client.

**Simple:**

Domain → Resolver → DNS hierarchy → IP → Client

### 3. What is an A record?

An A record maps a hostname to an IPv4 address.

### 4. What is an AAAA record?

An AAAA record maps a hostname to an IPv6 address.

### 5. What is CNAME?

CNAME stands for Canonical Name. It creates an alias from one hostname to another hostname.

### 6. What is MX?

An MX record specifies the mail servers responsible for receiving email for a domain.

### 7. What is NS?

An NS record identifies the authoritative name servers for a DNS domain.

### 8. What is DNS caching?

DNS caching stores DNS results temporarily so future lookups can be answered faster without repeatedly querying DNS servers.

### 9. What is a DNS resolver?

A DNS resolver is a service that receives DNS queries from clients and finds the required DNS information, either from its cache or by querying other DNS servers.

**Simple:**

Client → Resolver → DNS servers → Answer

### 10. What is the difference between a DNS resolver and DNS server?

A DNS resolver performs DNS lookups on behalf of clients, while a DNS server can host DNS records or provide DNS responses. In practice, the terms can overlap depending on the server's role.

### 11. What happens when DNS is unavailable?

Domain names may fail to resolve, so users may be unable to access services by hostname even if network connectivity itself is working.

**Scenario:**

Can ping 8.8.8.8, but google.com doesn't work?

I would suspect a DNS resolution problem and check the configured DNS server and DNS resolution.

**Excellent troubleshooting answer.**

### 12. What is the difference between hostname and domain name?

A hostname identifies a specific device or service, while a domain name identifies a DNS namespace or domain.

**Example:**

`www.example.com`

`www` → hostname  
`example.com` → domain

## 🟠 Important

### 13. What is a DNS query?

A DNS query is a request for DNS information, such as the IP address associated with a hostname.

### 14. What is recursive DNS?

In a recursive lookup, the resolver takes responsibility for finding the final answer on behalf of the client.

### 15. What is iterative DNS?

In an iterative lookup, a DNS server provides the best information it has, which may include a referral to another DNS server.

### 16. Recursive vs Iterative Query?

**Recursive**

The DNS resolver takes responsibility for finding the final answer for the client.

**Iterative**

A DNS server responds with the best information it has, potentially referring the requester to another DNS server.

**Simple:**

Recursive → "Find the answer for me."

Iterative → "Here is the best information I have; ask this server next."

### 17. What is the DNS hierarchy?

DNS uses a hierarchical structure consisting broadly of:

- Root DNS servers
- Top-Level Domain (TLD) servers
- Authoritative DNS servers

**Simple:**

Root → TLD → Authoritative → Record

### 18. What is an authoritative DNS server?

An authoritative DNS server is a DNS server that has the official DNS records for a domain and can provide authoritative answers for that domain.

### 19. What is a root DNS server?

Root DNS servers are at the top of the DNS hierarchy. They help direct DNS queries toward the appropriate TLD servers.

### 20. What is a TLD server?

A TLD server handles DNS information for a top-level domain such as `.com`, `.org`, `.net`, or country-code TLDs.

### 21. What is TTL in DNS?

TTL stands for Time To Live. It specifies how long a DNS response can normally be cached before it should be queried again.

**Simple:**

TTL = How long DNS information can be cached.

### 22. What is reverse DNS lookup?

A reverse DNS lookup finds a hostname associated with an IP address.

**Normal DNS:**

Hostname → IP address

**Reverse DNS:**

IP address → Hostname

### 23. What is a PTR record?

A PTR record is used for reverse DNS lookups, mapping an IP address to a hostname.

### 24. What is DNS propagation?

DNS propagation refers to the period during which changes to DNS records become visible across different DNS resolvers and cached systems.

## 🟡 Lower Priority

### 25. What is an SOA record?

SOA stands for Start of Authority. It contains important administrative information about a DNS zone, including information about the authoritative server and zone timing parameters.

### 26. What is an SRV record?

An SRV record specifies the location of services for a domain, including the hostname and port where a particular service can be reached.

### 27. What is DNS zone?

A DNS zone is a portion of the DNS namespace managed by a particular organization or administrative authority.

### 28. What is forward DNS lookup?

A forward DNS lookup resolves a hostname or domain name to an IP address.

**Example:**

`google.com → IP address`

### 29. What is DNS over HTTPS (DoH)?

DNS over HTTPS sends DNS queries through HTTPS, encrypting the DNS communication between the client and the resolver.

### 30. What is DNS over TLS (DoT)?

DNS over TLS sends DNS queries through an encrypted TLS connection, helping protect DNS queries from being read or modified in transit.

### 31. What is DNS troubleshooting?

DNS troubleshooting involves checking whether a hostname resolves correctly and determining whether the issue is with the client configuration, DNS resolver, DNS server, records, or connectivity.

Useful commands include:

```text
nslookup
dig
```

### For a fresher interview:

> I would first check whether the client has the correct DNS server configured, then test name resolution using tools such as nslookup or dig.
