# 15. NAT FUNDAMENTALS

## 🔴 VERY IMPORTANT

### 1. What is NAT?
Answer: NAT stands for Network Address Translation. It translates IP addresses between different address spaces, commonly between private and public IPv4 addresses.  

🧠 Memorize:  
NAT = Translates IP addresses

### 2. Why is NAT used?
Answer: NAT is commonly used to allow devices using private IPv4 addresses to communicate with public networks and to conserve public IPv4 addresses.  

🧠 Memorize:  
NAT = Private → Public + IPv4 conservation

### 3. What is a private IP?
Answer: A private IP address is an address used within private networks and is not directly routable on the public Internet.  

🧠 Memorize:  
Private IP = Internal network

### 4. What is a public IP?
Answer: A public IP address is an address that can be used for communication over the public Internet and is globally routable.  

🧠 Memorize:  
Public IP = Internet-facing

### 5. Difference between private and public IP?
Answer: Private IP addresses are used inside private networks, while public IP addresses are used for communication over the public Internet.  

🧠 Memorize:  
Private = Inside  
Public = Internet

### 6. What is Static NAT?
Answer: Static NAT creates a fixed one-to-one mapping between a private IP address and a public IP address.  

🧠 Memorize:  
Static NAT = 1 private ↔ 1 public

### 7. What is Dynamic NAT?
Answer: Dynamic NAT maps private IP addresses to public IP addresses from a configured pool of public addresses.  

🧠 Memorize:  
Dynamic NAT = Private → Public pool

### 8. What is PAT?
Answer: PAT stands for Port Address Translation. It allows multiple private devices to share one public IP address by using different port numbers.  

🧠 Memorize:  
PAT = Many private devices → One public IP + ports

### 9. NAT vs PAT
Answer:  
- NAT translates IP addresses.  
- PAT translates IP addresses and uses port numbers to allow multiple connections to share a public IP.  

🧠 Memorize:  
NAT = Address translation  
PAT = Address + Port translation

### 10. Why is NAT commonly used with IPv4?
Answer: NAT is commonly used with IPv4 because public IPv4 addresses are limited, and NAT allows many private devices to share fewer public IPv4 addresses.  

🧠 Memorize:  
IPv4 shortage → NAT helps conserve addresses

### 11. How does NAT allow private devices to access the Internet?
Answer: When a private device sends traffic to the Internet, the NAT device translates its private source address into a public address and tracks the connection so return traffic can be translated back to the private device.  

🧠 Memorize:  
Private device  
      ↓  
NAT  
      ↓  
Public IP  
      ↓  
Internet

## 🟠 IMPORTANT

### 12. What is NAT overload?
Answer: NAT overload is another name commonly used for PAT, where multiple private devices share one public IP address by using different port numbers.  

🧠 Memorize:  
NAT overload = PAT

### 13. What is inside local?
Answer: Inside local refers to the address of an internal host as it appears on the internal network, typically its private IP address.  

🧠 Memorize:  
Inside local = Internal/private address

### 14. What is inside global?
Answer: Inside global refers to the address representing an internal host to the outside network, typically a public IP address after NAT translation.  

🧠 Memorize:  
Inside global = Public representation

### 15. What happens when a private device accesses a public server?
Answer:  
- The private device sends traffic.  
- The NAT device receives it.  
- NAT translates the private source address.  
- The translated packet goes to the public server.  
- The response returns.  
- NAT translates the response back to the private device.  

🧠 Memorize:  
Private → NAT → Public Server → NAT → Private

### 16. Does NAT provide security?
Answer: NAT can provide a degree of isolation because private addresses are not directly exposed, but NAT itself is not a replacement for a firewall.  

🧠 Memorize:  
NAT ≠ Firewall

### 17. NAT vs firewall
Answer: NAT primarily translates addresses and ports, while a firewall filters traffic according to security rules.  

🧠 Memorize:  
NAT = Translation  
Firewall = Filtering

---

## 🟡 LOWER PRIORITY

### 18. Port forwarding
Answer: Port forwarding maps traffic arriving at a public IP and specific port to a private internal device and port.  

🧠 Memorize:  
Internet → Public IP:Port → Private Server

### 19. NAT traversal
Answer: NAT traversal refers to techniques that allow communication between devices when one or both devices are behind NAT.  

🧠 Memorize:  
NAT traversal = Communication through NAT

### 20. Static PAT
Answer: Static PAT creates a fixed mapping between a public IP/port and a private IP/port, commonly used to make an internal service reachable from outside.  

🧠 Memorize:  
Static PAT = Fixed public port → fixed private service
