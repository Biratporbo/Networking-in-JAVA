# 6. DHCP

## 🔴 Very Important

### 1. What is DHCP?

**DHCP** stands for **Dynamic Host Configuration Protocol**. It automatically provides network configuration information to clients.

### 2. Why use DHCP?

DHCP reduces **manual configuration** and automatically assigns network settings to devices.

### 3. What information does DHCP provide?

Typically:

- **IP address**
- **Subnet mask/prefix**
- **Default gateway**
- **DNS server**
- **Lease information**

### 4. Explain DORA.

**D — Discover**

The client looks for a DHCP server.

**O — Offer**

The server offers network configuration.

**R — Request**

The client requests the offered configuration.

**A — Acknowledgment**

The server confirms the lease.

> **Discover → Offer → Request → ACK**

### 5. What is DHCP Discover?

A client broadcasts a **DHCP Discover** message to locate available DHCP servers.

### 6. What is DHCP Offer?

The DHCP server responds with an **offer** containing proposed network configuration.

### 7. What is DHCP Request?

The client indicates which offered configuration it wants to accept.

### 8. What is DHCP ACK?

**DHCP ACK** confirms the configuration and lease for the client.

### 9. What is a DHCP lease?

A **DHCP lease** is the period for which a client is allowed to use an assigned IP address and configuration.

### 10. DHCP vs Static IP?

**DHCP** automatically assigns and manages addresses, while a **static IP** is manually configured and remains fixed unless changed.

### 11. What if DHCP server is unavailable?

Clients may fail to obtain valid network configuration. In IPv4 environments, some systems may self-assign an **APIPA address**, which usually provides only limited local connectivity.

---

## 🟠 Important

### 12. What is DHCP reservation?

A **DHCP reservation** ensures a particular device receives the same IP address based on its identifier, commonly its **MAC address**.

### 13. What is DHCP scope?

A **DHCP scope** is the range of IP addresses and associated configuration that a DHCP server can assign to clients for a particular network.

### 14. What is DHCP relay?

**DHCP relay** forwards DHCP messages between clients and a DHCP server when the server is on a different network.

### 15. Why is DHCP relay needed?

DHCP Discover messages are **broadcasts** and normally do not cross routers. A DHCP relay allows those requests to reach a DHCP server on another network.

### 16. What default gateway can DHCP provide?

DHCP can provide the **IP address of the default gateway** that clients should use to reach other networks.

### 17. What DNS information can DHCP provide?

DHCP can provide clients with the **IP addresses of DNS servers** they should use for name resolution.

---

## 🟡 Lower Priority

### 18. What is DHCP NAK?

**DHCP NAK** means the server rejects the client's DHCP request, indicating that the requested configuration or address is not valid for that client or network.

### 19. What is DHCP renewal?

Before a lease expires, the client attempts to **renew its lease** with the DHCP server so it can continue using the assigned address.

### 20. What is DHCP server redundancy?

**DHCP redundancy** uses multiple DHCP servers or other availability mechanisms so address assignment can continue if one server fails.
