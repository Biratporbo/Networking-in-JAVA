# 🌐 Networking Interview Preparations

This folder contains **concise notes** for revising computer networking concepts commonly discussed in technical interviews.  
The topics progress from **fundamentals → protocols → routing → services → security**.

---

## 📚 Recommended Study Order

1️⃣ **Models & Protocols** → TCP/IP, OSI, TCP vs UDP  
2️⃣ **Addressing** → IPv4, IPv6, Subnetting  
3️⃣ **Application Services** → HTTP/HTTPS, FTP, DNS, DHCP  
4️⃣ **Switching & Routing** → VLAN, OSPF, RIP  
5️⃣ **Security & Admin** → ACL, NAT, VPN, SSH, Port Security, Firewalls
