# Networking Interview Preparations

This folder contains concise notes for revising computer networking concepts commonly discussed in technical interviews. The topics move from networking fundamentals to protocols, routing, network services, and security.

## Recommended Study Order

1. Understand the **TCP/IP model**, **OSI model**, and the difference between **TCP** and **UDP**.
2. Review addressing concepts, including **IPv4**, **IPv6**, and **subnetting**.
3. Study common application and network services such as **HTTP/HTTPS**, **FTP**, **DNS**, and **DHCP**.
4. Learn switching and routing concepts, including **VLAN**, **OSPF**, and **RIP**.
5. Finish with network administration and security topics such as **ACL**, **NAT**, **VPN**, **SSH**, port security, and firewalls.
