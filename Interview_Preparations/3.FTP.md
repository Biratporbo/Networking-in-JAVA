# 3. FTP FUNDAMENTALS

## 🔴 Very Important

### 1. What is FTP?
FTP = **File Transfer Protocol**.  
Application-layer protocol used to transfer files between client and server.

### 2. What does FTP stand for?
FTP → File Transfer Protocol.

### 3. What is FTP used for?
Uploading, downloading, managing, and transferring files between computers over a network.

### 4. Does FTP use TCP or UDP?
FTP uses **TCP** because it requires reliable communication.

### 5. Which port does FTP use?
- Control connection → TCP 21  
- Active FTP data connection → TCP 20  

### 6. What are FTP control and data connections?
- **Control connection** → Commands + responses  
- **Data connection** → Files + directory listings  

### 7. Control vs Data Connection
| Control | Data |
|---------|------|
| Commands/responses | File data/listings |
| TCP 21 | Separate port |
| Persistent | Created as needed |

### 8. What is active FTP?
Client opens control connection → Server initiates data connection back to client.

### 9. What is passive FTP?
Client opens both control + data connections to server (server provides data port).

### 10. Active vs Passive FTP
| Active FTP | Passive FTP |
|------------|-------------|
| Server initiates data connection | Client initiates data connection |
| Firewall/NAT issues | Easier through firewalls/NAT |
| Server connects back | Client connects to server |

### 11. Is FTP secure?
Traditional FTP is **not secure** — usernames, passwords, and data sent in plain text.

### 12. FTP vs SFTP
- **FTP** → No encryption  
- **SFTP** → Secure FTP over SSH (encrypted)

### 13. FTP vs FTPS
- **FTP** → Traditional, unencrypted  
- **FTPS** → FTP + TLS encryption  
- **SFTP** → File transfer over SSH

### 14. Why is FTP insecure?
Credentials + data transmitted without encryption → vulnerable to interception.

### 15. What happens when a client connects to FTP server?
Client establishes TCP control connection (port 21), authenticates, sends commands, and opens data connection for file transfer.

**Important Ports:**  
- Control → TCP 21  
- Active data → TCP 20  
- Passive → Negotiated port range

## 🟠 Important

### 16. What is FTP authentication?
Verifying user identity with username + password.

### 17. What is anonymous FTP?
Access without personal account, usually restricted permissions.

### 18. What is an FTP server?
System providing file-transfer services, responding to client requests.

### 19. What is an FTP client?
Software connecting to FTP server to upload/download/manage files.

### 20. What is active mode?
Server initiates data connection back to client.

### 21. What is passive mode?
Client initiates data connection to server-selected port.

### 22. Why is passive FTP preferred behind firewalls/NAT?
Client initiates data connection → easier for firewalls/NAT to handle.

### 23. What is an FTP data connection?
Carries files + directory listings.

### 24. What is an FTP control connection?
Carries commands + responses (TCP port 21).

### 25. Common FTP commands
- **LIST** → List files  
- **GET** → Download file  
- **PUT** → Upload file  
- **PWD** → Show current directory  
- **CWD** → Change directory  

### 26. What is GET in FTP?
Download file from server → client.

### 27. What is PUT in FTP?
Upload file from client → server.

### 28. What is LIST in FTP?
Retrieve directory listing from server.

### 29. What is an FTP response code?
Numeric code indicating result/status of FTP command.

## 🟡 Lower Priority

### 30. FTP command channels
- Control channel → Commands/responses  
- Data channel → File transfers/listings  

### 31. FTP response-code categories
- 1xx → Positive preliminary  
- 2xx → Positive completion  
- 3xx → Positive intermediate  
- 4xx → Temporary negative  
- 5xx → Permanent negative  

### 32. ASCII transfer mode
Transfers text files with character conversion.

### 33. Binary transfer mode
Transfers raw bytes (images, executables, archives).

### 34. FTP over IPv6
FTP can operate using IPv6 addresses.

### 35. FTP firewall configuration
Firewalls must allow control + passive data port range. Passive FTP easier to configure.

### 36. FTP proxy operation
FTP proxy = intermediary between client + server, forwarding traffic and applying policies.

# 🧠 FTP 30-Second Revision

**Memorize this:**  
FTP = File Transfer Protocol, uses TCP (port 21 control, port 20 active data).  
Active FTP → Server initiates data connection.  
Passive FTP → Client initiates data connection (preferred behind firewalls).  
Traditional FTP insecure → use SFTP (SSH) or FTPS (TLS).  
Commands: LIST, GET, PUT, PWD, CWD.  
Modes: ASCII (text), Binary (raw bytes).

**Remember:**  
- Control → Commands/responses (TCP 21)  
- Data → Files/listings (TCP 20 or passive port)  
- Active → Server connects back  
- Passive → Client connects to server  
- FTP → Insecure  
- SFTP → Secure over SSH  
- FTPS → FTP + TLS  

**Interview answer:**  
> FTP is an application-layer protocol for transferring files between client and server. It uses TCP port 21 for control and separate data connections for file transfer. Active FTP has the server initiate the data connection, while passive FTP has the client initiate it, making passive mode more firewall-friendly. Traditional FTP is insecure, so secure alternatives like SFTP (over SSH) or FTPS (over TLS) are preferred.
