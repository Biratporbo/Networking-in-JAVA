# 1. TCP/IP FUNDAMENTALS

## 🔴 Very Important

### 1. What is TCP/IP?
TCP/IP stands for **Transmission Control Protocol/Internet Protocol**.  
It is a set of communication protocols used to connect devices and enable communication over networks, including the Internet.

### 2. What are the layers of the TCP/IP model?
The TCP/IP model has **4 layers**:
- Application Layer  
- Transport Layer  
- Internet Layer  
- Network Access Layer  

**Easy memory:**  
Application ↓ Transport ↓ Internet ↓ Network Access

### 3. Explain the TCP/IP model
- **Application Layer** → Provides services to applications.  
- **Transport Layer** → End-to-end communication (TCP/UDP).  
- **Internet Layer** → Logical addressing + routing (IP).  
- **Network Access Layer** → Communication over physical/local network.

### 4. TCP/IP vs OSI
| TCP/IP | OSI |
|--------|-----|
| 4-layer practical model | 7-layer reference model |
| Application combines Application + Presentation + Session | Separate layers |
| Transport | Transport |
| Internet | Network |
| Network Access | Data Link + Physical |

**Interview answer:**  
OSI is a **reference model** with 7 layers, while TCP/IP is a **practical protocol suite** with 4 layers, combining some OSI layers.

### 5. What is TCP?
TCP = **Transmission Control Protocol**.  
It is **connection-oriented**, reliable, and ensures ordered delivery of data.

### 6. TCP vs UDP
- **TCP → Connection-oriented, reliable, ordered**  
- **UDP → Connectionless, faster, no guarantee**

**Interview answer:**  
TCP provides reliable, ordered communication, while UDP is faster but does not guarantee delivery.

### 7. Why is TCP connection-oriented?
Because TCP establishes a **logical connection** before data transfer begins.

### 8. What is the TCP Three-Way Handshake?
Steps:
1. SYN → Client requests connection  
2. SYN-ACK → Server acknowledges + responds  
3. ACK → Client confirms  

**Diagram:**

> Client -------- SYN --------> Server
>
> Client <----- SYN+ACK ------- Server
>
>Client -------- ACK --------> Server
>
>Connection established


### 9. Explain SYN, SYN-ACK and ACK
- **SYN** → Client requests connection.  
- **SYN-ACK** → Server acknowledges + ready.  
- **ACK** → Client confirms.  

### 10. Why is the three-way handshake required?
To establish the connection, synchronize sequence numbers, and confirm readiness.

### 11. What happens after a TCP connection is established?
Client and server exchange data using sequence numbers, acknowledgements, flow control, and retransmission.

### 12. What is TCP connection termination?
Closing a connection using **FIN + ACK** messages.

### 13. What are FIN and ACK in termination?
- **FIN** → End of data from one side.  
- **ACK** → Acknowledges received message.  

### 14. What is a TCP segment?
Unit of data = **TCP header + application data**.

### 15. What is a TCP port?
Logical number identifying services:  
- HTTP → 80  
- HTTPS → 443  
- FTP → 21  
- SSH → 22  

### 16. What is a socket?
Endpoint of communication defined by **IP + Port**.

### 17. What is TCP reliability?
Ensured via acknowledgements, sequence numbers, retransmissions, and checksums.

### 18. How does TCP detect lost data?
Using acknowledgements, sequence numbers, duplicate ACKs, and timers.

### 19. What is retransmission?
Resending data when TCP detects loss.

### 20. What is TCP flow control?
Prevents sender from overwhelming the **receiver**.

### 21. What is TCP congestion control?
Prevents sender from overwhelming the **network**.

### 22. Flow vs Congestion Control
- Flow Control → Receiver  
- Congestion Control → Network  

### 23. What is TCP sequence number?
Identifies position of data bytes in stream.

### 24. What is TCP acknowledgement number?
Indicates next sequence number expected.

### 25. What happens when a TCP packet is lost?
TCP retransmits missing data.

## 🟠 Important

### 26. What is TCP sliding window?
Allows multiple bytes to be sent before ACKs.

### 27. What is a TCP window?
Amount of data that can be sent without ACK.

### 28. What is retransmission timeout (RTO)?
Time TCP waits for ACK before retransmitting.

### 29. What is a duplicate ACK?
Repeated ACK indicating missing segment.

### 30. What is a TCP handshake?
Standard connection setup = SYN, SYN-ACK, ACK.

### 31. What is TCP keep-alive?
Checks if idle connection is still active.

### 32. What is TCP checksum?
Detects errors in TCP header/data.

### 33. What is TCP MSS?
Maximum Segment Size = max TCP payload.

### 34. What is TCP MTU?
Maximum Transmission Unit = max IP packet size.

### 35. MSS vs MTU
- MSS → TCP data size  
- MTU → IP packet size  

### 36. What is TCP congestion avoidance?
Controls sending rate to reduce congestion.

### 37. What is slow start?
Congestion window grows rapidly until threshold.

### 38. What is fast retransmit?
Retransmit before timeout using duplicate ACKs.

### 39. What is full-duplex communication?
Both sides send/receive simultaneously (e.g., phone).

### 40. What is half-duplex communication?
Both sides communicate but not simultaneously (e.g., walkie-talkie).

### 41. Why is TCP slower than UDP?
TCP has more overhead (ACKs, retransmissions, ordering).

### 42. Applications using TCP
- HTTP/HTTPS  
- FTP  
- SSH  
- Email (SMTP, IMAP)

### 43. What happens when a TCP server is unreachable?
Client retries, then fails after timeout.

### 44. What is a TCP timeout?
Occurs when TCP waits too long for ACK/response.

## 🟡 Lower Priority

### 45. Explain TCP congestion-control algorithms
Includes **slow start, congestion avoidance, fast retransmit, fast recovery**.

### 46. What is TCP window scaling?
Option to advertise larger receive windows.

### 47. What is TCP SACK?
Selective Acknowledgement → Receiver informs sender of received blocks.

### 48. What is TCP delayed ACK?
Receiver waits briefly before sending ACK.

### 49. What is Nagle's algorithm?
Combines small packets to reduce overhead.

### 50. What is TCP reset (RST)?
Immediately terminates/rejects connection.

### 51. What is TIME_WAIT?
State after termination to ensure delayed packets expire.

### 52. Why does TIME_WAIT exist?
Prevents old packets interfering with new connections.

### 53. What is TCP simultaneous open?
Both endpoints send SYN at same time.

### 54. What is TCP retransmission backoff?
TCP increases wait time between retransmissions after repeated timeouts.

### 55. What is TCP urgent data?
Uses urgent pointer to indicate urgent data (rarely used today).

# 🧠 TCP/IP 30-Second Revision

**Memorize this:**  
TCP/IP = 4-layer practical protocol suite.  
TCP is reliable, connection-oriented, uses **three-way handshake**.  
UDP is faster, connectionless, no guarantee of delivery.  
Flow control protects **receiver**, congestion control protects **network**.  
Ports identify services, sockets = IP + Port.  
Reliability ensured via sequence numbers, ACKs, retransmissions.

**Remember:**  
- TCP → Reliable, ordered, connection-oriented  
- UDP → Fast, connectionless, no guarantee  
- Flow Control → Receiver  
- Congestion Control → Network  
- MSS → TCP payload size  
- MTU → IP packet size  
- TIME_WAIT → Safe connection closure  

**Interview answer:**  
> TCP/IP is a practical 4-layer protocol suite enabling communication across networks. TCP provides reliable, ordered delivery using mechanisms like sequence numbers, acknowledgements, and retransmissions, while UDP offers faster, connectionless communication without reliability guarantees.
