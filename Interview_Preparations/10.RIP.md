# 10. RIP FUNDAMENTALS

## 🔴 VERY IMPORTANT

### 1. What is RIP?
Answer: RIP stands for Routing Information Protocol. It is a dynamic routing protocol used by routers to exchange routing information.  

🧠 Memorize:  
RIP = Dynamic routing protocol

### 2. Is RIP dynamic or static?
Answer: RIP is a dynamic routing protocol because routers automatically exchange routing information.  

🧠 Memorize:  
RIP → Dynamic

### 3. Is RIP distance-vector or link-state?
Answer: RIP is a distance-vector routing protocol.  

🧠 Memorize:  
RIP = Distance Vector

### 4. What metric does RIP use?
Answer: RIP uses hop count as its routing metric.  

🧠 Memorize:  
RIP → Hop count

### 5. What is the maximum usable hop count in RIP?
Answer: The maximum usable hop count is 15.  
A hop count of 16 means the destination is considered unreachable.  

🧠 Memorize:  
RIP: 15 = usable, 16 = unreachable

### 6. What does a hop count of 16 mean?
Answer: In RIP, a hop count of 16 represents an unreachable network.  

🧠 Memorize:  
16 hops = unreachable

### 7. RIP vs OSPF
| RIP | OSPF |
|-----|------|
| Distance-vector | Link-state |
| Hop count | Cost |
| Maximum 15 usable hops | No RIP-style 15-hop limitation |
| Simpler | More scalable |
| Less suitable for large networks | Suitable for larger networks |

🧠 Memorize:  
RIP = Hop count  
OSPF = Cost + Link-state

## 🟠 IMPORTANT

### 8. What is RIPv1?
Answer: RIPv1 is the first version of RIP. It is a classful routing protocol and does not include subnet mask information in routing updates.  

🧠 Memorize:  
RIPv1 = Classful

### 9. What is RIPv2?
Answer: RIPv2 is an improved version of RIP that supports classless routing and carries subnet mask information.  

🧠 Memorize:  
RIPv2 = Classless + subnet mask

### 10. Difference between RIPv1 and RIPv2?
Answer: RIPv1 is classful and does not carry subnet mask information, while RIPv2 is classless and supports subnet masks.  

🧠 Memorize:  
v1 = Classful  
v2 = Classless

### 11. What is convergence?
Answer: Convergence is the process by which routers update their routing information so that all routers have a consistent view of the network after a topology change.  

🧠 Memorize:  
Convergence = Routers agree on current routes

### 12. Why isn't RIP suitable for large networks?
Answer: RIP is not ideal for large networks because it has a maximum usable hop count of 15, slower convergence, and less efficient routing compared with protocols such as OSPF.  

🧠 Memorize:  
RIP limitations = 15 hops + slower convergence + less scalable

## 🟡 LOWER PRIORITY

### 13. What is split horizon?
Answer: Split horizon is a routing technique where a router does not advertise a route back through the interface from which it learned that route. It helps prevent routing loops.  

🧠 Memorize:  
Don't advertise a route back where you learned it.

### 14. What is route poisoning?
Answer: Route poisoning is a technique where a failed route is advertised with an infinite metric so other routers know that the route is unreachable.  
In RIP, the infinite metric is 16.  

🧠 Memorize:  
Dead route → metric 16

### 15. What is a triggered update?
Answer: A triggered update is an immediate routing update sent when a significant routing change occurs instead of waiting for the normal update interval.  

🧠 Memorize:  
Routing change → immediate update
