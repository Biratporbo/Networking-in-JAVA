# 5. OSI MODEL

## 🔴 Very Important

### 1. What is the OSI model?

**OSI** stands for **Open Systems Interconnection**. It is a seven-layer conceptual model used to understand how data is transmitted between devices over a network.

### 2. Why was the OSI model created?

It was created to **standardize network communication** and provide a common framework for understanding how different networking technologies communicate.

### 3. Explain all 7 layers

| Layer | Name | Main Function |
|---|---|---|
| 7 | Application | Network services used by applications |
| 6 | Presentation | Data formatting, encryption, compression |
| 5 | Session | Establishes and manages communication sessions |
| 4 | Transport | End-to-end delivery, reliability and flow control |
| 3 | Network | IP addressing and routing |
| 2 | Data Link | Frames, MAC addressing and local delivery |
| 1 | Physical | Bits, signals, cables and physical transmission |

**Easy order:**

> Application → Presentation → Session → Transport → Network → Data Link → Physical

**Mnemonic:**

> **All People Seem To Need Data Processing**

### 4. Function of Physical Layer?

The **Physical Layer** transmits raw bits through physical media such as cables, fiber or wireless signals.

### 5. Function of Data Link Layer?

It provides node-to-node communication, uses **MAC addresses**, creates **frames**, and handles error detection at the data-link level.

### 6. Function of Network Layer?

It handles logical addressing using **IP addresses** and determines how packets are routed between networks.

### 7. Function of Transport Layer?

It provides **end-to-end communication** between applications and handles functions such as segmentation, flow control and, with TCP, reliable delivery.

### 8. Function of Session Layer?

It establishes, manages and terminates communication sessions between applications.

### 9. Function of Presentation Layer?

It handles data representation, including:

- Data formatting
- Encryption/decryption
- Compression

### 10. Function of Application Layer?

It provides network-related services directly to applications, such as:

- Web services
- Email
- File-transfer services

### 11. Which layer does IP operate at?

**Layer 3 — Network Layer**

### 12. Which layer does TCP operate at?

**Layer 4 — Transport Layer**

### 13. Which layer does UDP operate at?

**Layer 4 — Transport Layer**

### 14. Which layer does a router operate at?

A router primarily operates at **Layer 3 — Network Layer**, because it forwards packets based on IP addresses.

### 15. Which layer does a switch primarily operate at?

A traditional network switch primarily operates at **Layer 2 — Data Link Layer**, using MAC addresses to forward frames.

> **Note:** A Layer 3 switch can also perform routing.

### 16. What is encapsulation?

**Encapsulation** is the process of adding protocol information, such as headers, to data as it moves down the network layers before transmission.

**Simple:**

**Data → Segment → Packet → Frame → Bits**

### 17. What is decapsulation?

**Decapsulation** is the reverse process. As data moves up the layers at the receiving device, the corresponding headers are removed and the original data is delivered to the application.

### 18. OSI vs TCP/IP

**OSI** is a seven-layer conceptual reference model, while **TCP/IP** is the practical protocol suite used for Internet communication.

#### OSI

1. Application
2. Presentation
3. Session
4. Transport
5. Network
6. Data Link
7. Physical

#### TCP/IP

1. Application
2. Transport
3. Internet
4. Network Access

## 🟠 Important

### 19. What is a frame?

A **frame** is the Layer 2 data unit. It contains information such as MAC addresses and carries a network-layer packet.

### 20. What is a packet?

A **packet** is the Layer 3 data unit. It generally contains an IP header and the transport-layer data.

### 21. What is a segment?

A **segment** is commonly the Layer 4 data unit associated with TCP.

> **Note:** UDP's Layer 4 data unit is usually called a **datagram**.

### 22. What is a PDU?

**PDU** stands for **Protocol Data Unit**. It is the unit of data used at a particular networking layer.

| Layer | PDU |
|---|---|
| Transport | Segment / Datagram |
| Network | Packet |
| Data Link | Frame |
| Physical | Bits |

### 23. MAC Address vs IP Address

A **MAC address** is a Layer 2 hardware/link-layer identifier used for local network communication, while an **IP address** is a Layer 3 logical address used for communication across networks.

**Remember:**

- **MAC → Local delivery**
- **IP → Network-to-network delivery**

### 24. Why is OSI useful for troubleshooting?

It helps troubleshoot problems **layer by layer** instead of randomly checking everything.

**Example:**

1. Physical
2. Data Link
3. Network
4. Transport
5. Application

If the cable is disconnected, there is no point starting with the application.

### 25. At which layer does Ethernet operate?

Ethernet primarily operates at **Layer 2**, with physical signaling aspects at **Layer 1**.

### 26. At which layer does ARP operate?

For an interview:

> ARP maps an IPv4 address to a MAC address on a local network. It operates across the boundary between Layer 2 and Layer 3, so I would describe it as a **Layer 2/Layer 3-related protocol** rather than fitting it strictly into one OSI layer.

This is a safer answer than simply saying **"Layer 3."**

## 🟡 Lower Priority

### 27. Limitations of OSI?

OSI is mainly a **conceptual reference model**. Real-world protocols do not always fit perfectly into its seven layers, and some layers are often combined in practical networking.

### 28. Why is Session Layer less visible today?

Modern protocols and applications often handle session-management functions themselves, so a separate **Session Layer** is not always clearly visible.

### 29. Why isn't Presentation Layer usually separate?

Modern application protocols and software often handle data formatting, encryption and compression themselves, so these functions are frequently integrated into the **Application Layer**.

# Quick Revision

## OSI Layers

| Layer | Name | Key Concept |
|---|---|---|
| **7** | Application | Services |
| **6** | Presentation | Format / Encrypt / Compress |
| **5** | Session | Sessions |
| **4** | Transport | TCP / UDP |
| **3** | Network | IP / Routing |
| **2** | Data Link | MAC / Frames |
| **1** | Physical | Bits / Signals |

## Important Protocol & Device Mapping

- **IP → Layer 3**
- **TCP → Layer 4**
- **UDP → Layer 4**
- **Ethernet → Layer 2 + Layer 1**
- **Switch → Layer 2**
- **Router → Layer 3**
- **ARP → Layer 2/3 boundary**

## Data Units

**Data → Segment/Datagram → Packet → Frame → Bits**
