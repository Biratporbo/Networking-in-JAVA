# 8. OSPF — Interview Answers

## 🔴 Very Important

### 1. What is OSPF?

OSPF stands for Open Shortest Path First. It is a dynamic interior gateway routing protocol that uses a link-state approach to find the best path within a network.

**Remember:**

OSPF = Dynamic + Link-State + SPF

### 2. Is OSPF static or dynamic?

OSPF is a dynamic routing protocol. Routers automatically learn and update routes by exchanging routing information.

### 3. Is OSPF distance-vector or link-state?

OSPF is a link-state routing protocol.

### 4. What algorithm does OSPF use?

OSPF uses Dijkstra's Shortest Path First algorithm, commonly called the SPF algorithm.

### 5. What is SPF?

SPF stands for Shortest Path First. It is the algorithm OSPF uses to calculate the best paths through the network based on the information in its link-state database.

### 6. What is OSPF cost?

OSPF cost is the metric used to select the best route. A lower total cost is preferred over a higher cost.

**Simple:**

Lower cost = better path.

### 7. What is an OSPF area?

An OSPF area is a logical division of an OSPF network. Areas help organize the network and reduce the amount of routing information that every router needs to process.

### 8. What is Area 0?

Area 0 is the OSPF backbone area.

### 9. Why is Area 0 important?

Area 0 is important because it acts as the backbone for communication between different OSPF areas. In a normal multi-area OSPF design, other areas connect to the backbone.

### 10. Why is OSPF preferred for large networks?

OSPF is suitable for large networks because it supports hierarchical areas, converges efficiently, and provides more scalability than simpler protocols such as RIP.

## 🟠 Important

### 11. What is an LSA?

LSA stands for Link-State Advertisement. It is information that OSPF routers exchange to describe network topology and link states.

**Easy memory:**

LSA = information about links/topology

### 12. What is an LSDB?

LSDB stands for Link-State Database. It contains the link-state information that OSPF routers use to understand the network topology and calculate routes.

**Think:**

LSA → information  
LSDB → database containing that information

### 13. What is an OSPF neighbor?

An OSPF neighbor is another OSPF router with which a router has established an OSPF relationship and exchanges routing information.

### 14. What is OSPF convergence?

OSPF convergence is the process by which routers update their routing information and reach a consistent view of the network after a topology change.

**Example:**

If a link fails, OSPF detects the change, updates its information, recalculates routes and installs the new best path.

### 15. What is DR?

DR stands for Designated Router. On certain multi-access networks, the DR helps reduce the number of OSPF adjacencies and routing-information exchanges between routers.

### 16. What is BDR?

BDR stands for Backup Designated Router. It acts as a backup to the DR and can take over if the DR fails.

### 17. Why are DR and BDR used?

DR and BDR are used mainly on multi-access networks to reduce unnecessary OSPF adjacency relationships and make routing information exchange more efficient.

**Easy example:**

Without DR/BDR:

R1 ↔ R2  
↕ ↘ ↕  
R3 ↔ R4

With DR/BDR, routers can organize their relationships around the designated router, reducing unnecessary full adjacencies.

### 18. What is single-area OSPF?

Single-area OSPF is an OSPF network where all routers participate in one OSPF area, commonly Area 0.

### 19. What is multi-area OSPF?

Multi-area OSPF divides a large OSPF network into multiple areas connected through the backbone Area 0.

**Simple:**

Area 1 ── Area 0 ── Area 2  
             │  
           Area 3

### 20. OSPF vs RIP

| OSPF | RIP |
|---|---|
| Link-state | Distance-vector |
| Uses cost | Uses hop count |
| Uses SPF | Uses Bellman-Ford-style distance-vector approach |
| More scalable | Less scalable |
| Faster convergence in typical designs | Generally slower |
| Suitable for larger networks | Suitable for smaller/simple networks |

**Interview answer:**

OSPF is a link-state routing protocol that uses cost and SPF, while RIP is a distance-vector protocol that uses hop count. OSPF is generally more scalable and suitable for larger networks.

## 🟡 Lower Priority

You should understand these, but don't spend too much time memorizing detailed configuration.

### 21. What are OSPF packet types?

There are five main OSPF packet types:

- **Hello** — discovers and maintains neighbors.
- **Database Description (DBD)** — summarizes the LSDB.
- **Link-State Request (LSR)** — requests specific information.
- **Link-State Update (LSU)** — sends LSAs.
- **Link-State Acknowledgment (LSAck)** — acknowledges LSAs.

**Quick memory:**

Hello → DBD → LSR → LSU → LSAck

### 22. What are OSPF neighbor states?

Common OSPF neighbor states include:

Down → Init → 2-Way → ExStart → Exchange → Loading → Full

**For a fresher interview, say:**

These states describe the process through which OSPF routers discover each other, exchange database information, request missing information and eventually reach full adjacency.

**If they ask "Which state indicates a fully established adjacency?"**

Full.

### 23. What is OSPF authentication?

OSPF authentication is a security mechanism used to verify OSPF routing messages between participating routers so unauthorized devices cannot easily form OSPF relationships.

### 24. What is OSPF route summarization?

Route summarization combines multiple routes into a summarized route, reducing the amount of routing information that needs to be advertised and processed.

OSPF = Open Shortest Path First. It is a dynamic link-state routing protocol. It uses Dijkstra's SPF algorithm and cost as its metric. OSPF can use areas for scalability, with Area 0 acting as the backbone. Routers exchange LSAs and maintain an LSDB to calculate the best routes.
