6. FIREWALL FUNDAMENTALS
🔴 Very Important
1. What is a firewall?

A firewall is a security system that monitors and controls network traffic according to defined security rules.

2. Why use firewalls?

Firewalls help prevent unauthorized access and control which network traffic is allowed to enter or leave a system or network.

3. How does a firewall control traffic?

It evaluates traffic against configured rules based on information such as source/destination IP, port, protocol, connection state, and sometimes application-level information.

4. What is packet filtering?

Packet filtering examines network packets and allows or blocks them based on predefined criteria such as IP addresses, ports and protocols.

5. What is a stateful firewall?

A stateful firewall tracks the state of network connections and can make decisions based on whether traffic belongs to an established or related connection.

6. What is a stateless firewall?

A stateless firewall evaluates each packet independently based mainly on configured packet attributes and does not maintain connection state.

7. Stateful vs Stateless

Stateful → remembers connection state.
Stateless → evaluates packets independently.

8. What is an inbound rule?

An inbound rule controls traffic entering a system or network.

9. What is an outbound rule?

An outbound rule controls traffic leaving a system or network.

10. What is default-deny?

Default-deny means traffic is blocked unless an explicit rule allows it.

Security principle:

Deny by default, allow only what is required.

11. Can a firewall block a port?

Yes. A firewall can allow or block traffic based on destination or source ports, depending on the rule and firewall capabilities.

12. Can a firewall block an IP?

Yes. Firewall rules can allow or deny traffic based on source or destination IP addresses.

13. Firewall vs ACL?

An ACL is a set of traffic filtering rules, often applied on network devices. A firewall is a broader security control that can inspect and control traffic and may provide stateful inspection and other security capabilities.

🟠 Important
14. What is a Next-Generation Firewall?

A Next-Generation Firewall, or NGFW, provides traditional firewall functions along with more advanced capabilities such as application awareness, deeper inspection, and integration with additional security controls.

15. What is application-layer filtering?

Application-layer filtering examines traffic at a higher level to identify and control specific applications or application behaviors rather than relying only on IP addresses and ports.

16. What is a firewall rule?

A firewall rule is a condition and action that determines whether particular traffic should be allowed, denied, logged, or otherwise handled.

17. What is a firewall policy?

A firewall policy is the overall collection and organization of security rules that determine how traffic is controlled.

18. What is DMZ?

DMZ stands for Demilitarized Zone. It is a separate network segment used to host services that need to be accessible from less-trusted networks while isolating them from the internal network.

19. Why use a DMZ?

A DMZ provides an additional security boundary so that if a publicly accessible server is compromised, the attacker's direct access to the internal network can be limited.

🟡 Lower Priority
20. IDS vs IPS?

IDS — Intrusion Detection System

Detects and alerts about suspicious activity.

IPS — Intrusion Prevention System

Detects suspicious activity and can actively block or prevent it.

21. Firewall vs IDS?

A firewall primarily controls traffic according to security rules, while an IDS monitors traffic for suspicious or malicious activity and generates alerts.

22. Firewall vs IPS?

A firewall controls network access based on defined rules, while an IPS actively detects and can block malicious traffic based on security analysis.

23. What is a Proxy Firewall?

A proxy firewall acts as an intermediary between clients and external servers and can inspect traffic at the application level.

24. What is a Web Application Firewall?

A Web Application Firewall, or WAF, protects web applications by filtering HTTP/HTTPS traffic and helping defend against attacks such as SQL injection and cross-site scripting.
