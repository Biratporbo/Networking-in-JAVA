# 12. PORT SECURITY — Interview Answers

## 🔴 Very Important

### 1. What is Port Security?

Port Security is a switch security feature that controls which devices are allowed to connect through a switch port, commonly using MAC addresses.

### 2. Why is Port Security used?

It helps prevent unauthorized devices from connecting to the network through switch ports.

### 3. What is a MAC address?

A MAC address is a link-layer address used to identify a network interface on a local network.

**Typically:**

48 bits, represented in hexadecimal.

**Example:**

00:1A:2B:3C:4D:5E

### 4. How does Port Security work?

Port Security limits which MAC addresses can be learned or allowed on a switch port. If an unauthorized MAC address appears, the switch can take a configured violation action.

### 5. What happens when an unauthorized device connects?

The switch detects a MAC address that violates the port-security configuration and takes the configured violation action, such as dropping traffic or shutting down the port.

### 6. What is MAC address limiting?

MAC address limiting means restricting the number or specific set of MAC addresses that are allowed on a switch port.

**Example:**

A port may be configured to allow only one device.

### 7. What is Sticky MAC?

Sticky MAC allows a switch to dynamically learn a device's MAC address on a port and treat that learned address as a secure MAC address according to the configuration.

**Easy memory:**

Sticky MAC = Learn the MAC and secure it to the port.

### 8. What is the maximum number of secure MAC addresses?

The maximum number of secure MAC addresses that can be configured on a port depends on the switch platform and configuration. A port can be configured to allow one or multiple secure MAC addresses.

**Interview answer:**

Port Security can limit the number of secure MAC addresses allowed on a switch port.

### 9. What is a secure MAC address?

A secure MAC address is a MAC address that the switch is configured to allow on a port under Port Security.

### 10. What is a Port Security violation?

A Port Security violation occurs when a MAC address that is not permitted by the port-security configuration appears on the secured port.

## 🟠 Important

### 11. What are Port Security violation modes?

Common Cisco-style violation modes are:

- **Protect**
- **Restrict**
- **Shutdown**

### 12. What happens in Protect mode?

Unauthorized traffic is dropped, while the port remains operational. The switch does not generate the same level of violation notification as restrict mode.

### 13. What happens in Restrict mode?

Unauthorized traffic is dropped, but the violation can also generate notifications/counters, depending on the platform.

### 14. What happens in Shutdown mode?

A security violation causes the port to be placed into an error-disabled state, effectively shutting down the port until it is recovered according to the device configuration.

**Easy memory:**

Protect → Drop  
Restrict → Drop + Report  
Shutdown → Disable Port

### 15. Port Security vs ACL

Port Security controls which devices can connect to a switch port, usually based on MAC addresses. ACLs control network traffic based on criteria such as IP addresses, protocols and ports.

### 16. Can Port Security work with multiple MAC addresses?

Yes. A switch port can be configured to allow multiple secure MAC addresses, depending on the platform and configuration.

### 17. What is static secure MAC?

A static secure MAC is a MAC address manually configured as an allowed secure MAC address on a switch port.

### 18. What is dynamic secure MAC?

A dynamic secure MAC is a MAC address learned dynamically by the switch and treated as a secure MAC address according to the Port Security configuration.

### 19. What is the difference between Sticky MAC and Static MAC?

Static MAC addresses are manually configured by the administrator, while Sticky MAC allows the switch to dynamically learn MAC addresses and use them as secure addresses according to the configuration.

**Simple:**

Static MAC → Manually configured  
Sticky MAC → Dynamically learned

## 🟡 Lower Priority

### 20. What is MAC flooding?

MAC flooding is an attack in which an attacker sends many fake or spoofed MAC addresses to overwhelm a switch's MAC address table.

### 21. What is CAM table overflow?

A CAM table overflow occurs when a switch's MAC address table becomes overwhelmed with entries, potentially causing the switch to flood traffic in ways that can be exploited by an attacker.

### 22. Relationship between Port Security and MAC address tables?

A switch maintains a MAC address table to associate MAC addresses with ports. Port Security adds restrictions on which MAC addresses can be learned or used on particular ports.

### 23. What is error-disabled state?

An error-disabled state is a condition where a switch disables a port because of a configured security or other operational violation.

### 24. What is MAC address aging?

MAC address aging is the process by which dynamically learned MAC addresses are removed from the switch's MAC address table after they have not been seen for a configured period.

### 25. Can Port Security protect against MAC spoofing?

Port Security can help limit unauthorized MAC addresses on a switch port, but it is not a complete defense against all forms of MAC spoofing. Its effectiveness depends on the configuration and the attack scenario.

### 26. What happens if a legitimate device is replaced?

If Port Security is configured with a specific secure MAC address, the replacement device may trigger a violation because its MAC address is different. The administrator may need to update the secure MAC configuration.

### 27. What is Port Security on an access port?

Port Security is commonly configured on access ports to restrict which end devices are allowed to connect to the switch.

### 28. Can Port Security be used on trunk ports?

Port Security support and behavior on trunk ports depend on the switch platform and configuration. For a fresher interview, Port Security is most commonly associated with access ports.
